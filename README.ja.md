# Ripper Search

[← 言語一覧](README.md)

Booth、Gumroad、itch.io などのストアを見ながら、Chrome から [Ripper.Store](https://forum.ripper.store) フォーラムでアセットを検索できます。

## ダウンロードとインストール

### 1. ダウンロード

👉 **[最新版をダウンロード](https://github.com/T1NG4/ripper-search/releases/latest)**

`ripper-search-v1.0.0.zip`（またはページ上の最新版）を取得してください。

### 2. 展開

ZIP を右クリック → **すべて展開**。保存したフォルダの場所を覚えておいてください。

### 3. Chrome にインストール

1. Chrome で `chrome://extensions` を開く
2. 右上の **デベロッパーモード** をオン
3. **パッケージ化されていない拡張機能を読み込む** をクリック
4. 展開した**フォルダ**を選択（ZIP ファイルではない）
5. 完了！ツールバーに Ripper Search のアイコンが表示されます

### 4. 使い方

1. [forum.ripper.store](https://forum.ripper.store/login) にログイン
2. Booth（または対応ストア）で商品ページを開く
3. Chrome の **Ripper Search** アイコンをクリック

---

## 機能

- ページの商品をフォーラムで**自動検索**
- **ダウンロード (DL)** 投稿とディスカッションを分離表示
- **LF リクエスト**の投稿と追跡
- 新しい DL の**お気に入りと通知**
- **ダウンロード**と検索**履歴**
- 投稿の**いいね**と日時表示
- **6 言語**の UI

## 対応ストア

Booth · Gumroad · Jinxxy · Payhip · itch.io · BuiltByBit · Unity Asset Store · Etsy
