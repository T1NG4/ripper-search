# User Guide — Ripper Search

## Quick start

1. Install the extension ([README](../README.md))
2. Log in at [forum.ripper.store](https://forum.ripper.store/login)
3. Open a product page on a supported store (e.g. Booth)
4. Click the **Ripper Search** icon to open the panel

## Tabs

### Search

- Auto-search on panel open (configurable)
- Search by product name or URL
- Results split into **Downloads Found** and **Discussions**
- Actions: Download, Bump, Favorite, Upvote, Post LF request
- Date/time and like count on each card

### Requests

- Tracks favorited threads and your LF (Looking For) posts
- Status badges: moderation queue, pending, watching, new DL, solved
- **Update scan** checks for new downloads
- Browser notifications (optional in Settings)

### Downloads

- Paste a download URL manually
- Or use **Download** on DL search results
- Hidelink URLs open in a new tab (forum-protected links)

### History

- Search history saved locally; **Repeat** to search again

### Settings

- Language, LF tags, bump message, export/import, per-site toggles

## FAQ

**Login required** — Forum session needed for search, upvote, and LF posts.

**LF posts in moderation** — New requests go to the mod queue before becoming a public topic.

**Unverified extension warning** — Expected with manual ZIP install; Chrome Web Store listing removes it.
