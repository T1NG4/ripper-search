# Guide d'utilisation — Ripper Search

[← Langues](GUIA.md) · [Installation](README.fr.md)

## Avant de commencer

1. [Installez l'extension](README.fr.md#télécharger-et-installer)
2. Connectez-vous sur [forum.ripper.store](https://forum.ripper.store/login)
3. Ouvrez un produit sur Booth (ou une autre boutique supportée)
4. Cliquez sur l'icône **Ripper Search** dans Chrome

Si vous voyez « Connectez-vous au forum », cliquez sur **Ouvrir la connexion**.

---

## Onglet Recherche

- **Rechercher par nom** ou **par URL**
- **Un mot** ou **Tous les mots**
- **Téléchargements trouvés** vs **Discussions**
- Boutons : **Télécharger**, **Bump**, **★ Favori**, **♡ Vote**, **Publier demande LF**

---

## Onglet Demandes

Suit les favoris et demandes LF. Statuts : file de modération, en analyse, surveillance, nouveau DL, résolu.

**Actualiser le scan** vérifie les nouveautés. Notifications dans **Paramètres**.

## FAQ

### Faut-il être connecté au forum ?

Oui.

### La demande LF n'apparaît pas ?

Elle passe d'abord par la **modération**. Vérifiez l'onglet **Demandes**.

### Le téléchargement n'a pas marché ?

Les liens protégés s'ouvrent dans un nouvel onglet. Certains sites demandent une vérification humaine.

### Extension non vérifiée ?

Normal lors de l'installation via ZIP. Téléchargez uniquement depuis les [Releases officielles](https://github.com/T1NG4/ripper-search/releases).

### Comment mettre à jour ?

Téléchargez la nouvelle version, supprimez l'ancienne dans `chrome://extensions` et réinstallez.
