# Ripper Search

[← Все языки](README.md)

Ищите ассеты на форуме [Ripper.Store](https://forum.ripper.store) прямо из Chrome, пока просматриваете Booth, Gumroad, itch.io и другие магазины.

## Скачать и установить

### 1. Скачать

👉 **[Скачать последнюю версию](https://github.com/T1NG4/ripper-search/releases/latest)**

Загрузите файл `ripper-search-v1.0.0.zip` (или новейшую версию на странице).

### 2. Распаковать

Правый клик по ZIP → **Извлечь всё**. Запомните, куда сохранена папка.

### 3. Установить в Chrome

1. Откройте Chrome и перейдите: `chrome://extensions`
2. Включите **Режим разработчика** (справа вверху)
3. Нажмите **Загрузить распакованное расширение**
4. Выберите **распакованную папку** (не ZIP)
5. Готово! Иконка Ripper Search появится на панели

### 4. Использование

1. Войдите на [forum.ripper.store](https://forum.ripper.store/login)
2. Откройте товар на Booth (или другом поддерживаемом магазине)
3. Нажмите иконку **Ripper Search** в Chrome

## Возможности

- **Автопоиск** товара со страницы на форуме
- Посты с **загрузкой (DL)** отдельно от обсуждений
- **LF-запросы** — публикация и отслеживание
- **Избранное и уведомления** о новых DL
- **Загрузки** и **история** поиска
- **Лайки** и дата/время постов
- Интерфейс на **6 языках**
