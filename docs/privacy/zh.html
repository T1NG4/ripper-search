隐私政策

更新日期：2026年9月

Ripper Search 是一款帮助您在 Ripper.Store 论坛搜索的 Chrome 扩展。

摘要

  • 我们不在自己的服务器上收集您的数据。
  • 除正常使用论坛和商店外，一切数据保留在浏览器中。

保存在您电脑上的内容

设置、搜索历史、监控的请求和下载列表均本地保存在 Chrome 中。

Ripper.Store 论坛

登录后，扩展使用您的会话进行搜索、点赞和发帖。我们看不到您的密码。

商店（Booth、Gumroad 等）

扩展读取当前页面的名称和链接以构建论坛搜索。这些信息不会发送到 Ripper Search 服务器。

Chrome 权限

权限原因
存储保存偏好和历史
Cookie使用论坛登录
通知有新下载时提醒
下载点击时下载文件

我们不会做的事

  • 无跟踪或广告
  • 不出售数据
  • 扩展内无需注册
