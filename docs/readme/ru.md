# Ripper Search

[← Все языки](../../README.md)

Ищите ассеты [Ripper.Store](https://forum.ripper.store) в Chrome, просматривая Booth, Gumroad, itch.io и другие магазины.

## Установка

Расширение распространяется **только через Chrome Web Store**.

1. Откройте **[Chrome Web Store](https://chromewebstore.google.com/search/Ripper%20Search)** и найдите **Ripper Search**
2. Нажмите **Установить** (Add to Chrome)
3. Подтвердите установку
4. Иконка Ripper Search появится на панели Chrome

## Использование

1. Войдите на [forum.ripper.store](https://forum.ripper.store/login)
2. Откройте товар на Booth (или в другом поддерживаемом магазине)
3. Нажмите иконку **Ripper Search** в Chrome

---

## Возможности

- **Автопоиск** товара со страницы на форуме
- Посты **DL** отдельно от обсуждений
- **LF-запросы** — публикация и отслеживание
- **Избранное и уведомления**
- **Загрузки** и **история** поиска
- **Лайки** и дата/время постов
- Интерфейс на **6 языках**

## Поддерживаемые магазины

Booth · Gumroad · Jinxxy · Payhip · itch.io · BuiltByBit · Unity Asset Store · Etsy
