# Ripper Search

[← 言語一覧](../../README.md)

Booth、Gumroad、itch.io などを見ながら Chrome で [Ripper.Store](https://forum.ripper.store) のアセットを検索。

## インストール

拡張機能は **Chrome ウェブストアのみ** で配布されています。

1. **[Chrome ウェブストア](https://chromewebstore.google.com/search/Ripper%20Search)** を開き **Ripper Search** を検索
2. **Chrome に追加** をクリック
3. インストールを確認
4. ツールバーに Ripper Search のアイコンが表示されます

## 使い方

1. [forum.ripper.store](https://forum.ripper.store/login) にログイン
2. Booth（または対応ストア）で商品ページを開く
3. Chrome の **Ripper Search** アイコンをクリック

---

## 機能

- ページの商品をフォーラムで**自動検索**
- **DL** 投稿とディスカッションを分離表示
- **LF リクエスト**の投稿と追跡
- **お気に入りと通知**
- **ダウンロード**と検索**履歴**
- 投稿の**いいね**と日時表示
- **6 言語** UI

## 対応ストア

Booth · Gumroad · Jinxxy · Payhip · itch.io · BuiltByBit · Unity Asset Store · Etsy
