# Ripper Search

[← 所有语言](../../README.md)

在浏览 Booth、Gumroad、itch.io 等商店时，通过 Chrome 在 [Ripper.Store](https://forum.ripper.store) 论坛搜索资源。

## 安装

扩展仅通过 **Chrome 网上应用店** 分发。

1. 打开 **[Chrome 网上应用店](https://chromewebstore.google.com/search/Ripper%20Search)** 并搜索 **Ripper Search**
2. 点击 **添加至 Chrome**
3. 确认安装
4. 工具栏会出现 Ripper Search 图标

## 使用

1. 登录 [forum.ripper.store](https://forum.ripper.store/login)
2. 在 Booth（或其他支持的商店）打开商品页面
3. 点击 Chrome 中的 **Ripper Search** 图标

---

## 功能

- 自动在论坛**搜索**当前页面商品
- **下载 (DL)** 帖子与讨论分开显示
- **LF 请求** — 发布并跟踪 Looking For
- **收藏与通知** — 有新下载时提醒
- **下载**和搜索**历史**
- 帖子**点赞**与日期时间
- **6 种语言**界面

## 支持的商店

Booth · Gumroad · Jinxxy · Payhip · itch.io · BuiltByBit · Unity Asset Store · Etsy
