# Ripper Search

[← 所有语言](../../README.md)

在浏览 Booth、Gumroad、itch.io 等商店时，通过 Chrome 在 [Ripper.Store](https://forum.ripper.store) 论坛搜索资源。

## 下载与安装

### 1. 下载

👉 **[下载最新版本](https://github.com/T1NG4/ripper-search/releases/latest)**

下载 `ripper-search-v1.0.0.zip`（或页面上的最新版本）。

### 2. 解压

右键 ZIP → **全部提取**。记住文件夹位置。

### 3. 在 Chrome 中安装

1. 打开 Chrome，访问：`chrome://extensions`
2. 开启右上角的 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择**解压后的文件夹**（不是 ZIP 文件）
5. 完成！工具栏会出现 Ripper Search 图标

### 4. 使用

1. 登录 [forum.ripper.store](https://forum.ripper.store/login)
2. 在 Booth（或其他支持的商店）打开商品页面
3. 点击 Chrome 中的 **Ripper Search** 图标

## 功能

- 自动在论坛**搜索**当前页面商品
- **下载 (DL)** 帖子与讨论分开显示
- **LF 请求** — 发布并跟踪 Looking For
- **收藏与通知** — 有新下载时提醒
- **下载**和搜索**历史**
- 帖子**点赞**与日期时间
- **6 种语言**界面

## 支持的商店
