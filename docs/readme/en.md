# Ripper Search

[← All languages](../../README.md)

Search [Ripper.Store](https://forum.ripper.store) forum assets from Chrome while browsing Booth, Gumroad, itch.io, and other stores.

## Download and install

### 1. Download

👉 **[Download the latest version](https://github.com/T1NG4/ripper-search/releases/latest)**

Get the `ripper-search-v1.0.0.zip` file (or the newest version on the page).

### 2. Extract

Right-click the ZIP → **Extract all**. Remember where you saved the folder.

### 3. Install in Chrome

1. Open Chrome and go to: `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked**
4. Select the **extracted folder** (not the ZIP file)
5. Done! The Ripper Search icon appears in the toolbar

### 4. Use it

1. Log in at [forum.ripper.store](https://forum.ripper.store/login)
2. Open a product on Booth (or another supported store)
3. Click the **Ripper Search** icon in Chrome

## Features

- **Auto-search** for the current page item on the forum
- **Download (DL)** posts separated from discussions
- **LF requests** — post and track Looking For topics
- **Favorites and notifications** when new downloads appear
- **Downloads** and search **history**
- **Upvote** posts with date/time
- UI in **6 languages**

## Supported stores

Booth · Gumroad · Jinxxy · Payhip · itch.io · BuiltByBit · Unity Asset Store · Etsy
