# Ripper Search

[← All languages](../../README.md)

Search [Ripper.Store](https://forum.ripper.store) assets from Chrome while browsing Booth, Gumroad, itch.io and other stores.

## Install

The extension is distributed **only through the Chrome Web Store**.

1. Open the **[Chrome Web Store](https://chromewebstore.google.com/search/Ripper%20Search)** and search for **Ripper Search**
2. Click **Add to Chrome**
3. Confirm the installation
4. The Ripper Search icon appears in your toolbar

## Use

1. Log in at [forum.ripper.store](https://forum.ripper.store/login)
2. Open a product on Booth (or another supported store)
3. Click the **Ripper Search** icon in Chrome

---

## Features

- **Auto-search** the current page item on the forum
- **Download (DL)** posts separated from discussions
- **LF requests** — post and track Looking For
- **Favorites and notifications** for new downloads
- **Downloads** and search **history**
- **Upvote** posts and see date/time
- **6 languages** UI

## Supported stores

Booth · Gumroad · Jinxxy · Payhip · itch.io · BuiltByBit · Unity Asset Store · Etsy
