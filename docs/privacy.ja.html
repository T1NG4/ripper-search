プライバシーポリシー

更新日: 2026年9月

Ripper Search は Ripper.Store フォーラムを検索する Chrome 拡張機能です。

概要

  • 当方のサーバーでデータを収集しません。
  • フォーラムやストアを通常利用する場合を除き、すべてブラウザ内に留まります。

コンピュータに保存されるもの

設定、検索履歴、監視中のリクエスト、ダウンロードリストは Chrome にローカル保存されます。

Ripper.Store フォーラム

ログイン中は、セッションを使って検索・いいね・投稿します。パスワードは見えません。

ストア（Booth、Gumroad など）

現在のページの名前とリンクを読み取り、フォーラム検索を組み立てます。Ripper Search のサーバーには送りません。

Chrome の権限

権限理由
ストレージ設定と履歴の保存
Cookieフォーラムログインの利用
通知新しい DL のお知らせ
ダウンロードクリック時のファイル取得

行わないこと

  • トラッキングや広告なし
  • データの販売なし
  • 拡張機能内の登録なし
