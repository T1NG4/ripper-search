Privacy Policy — Ripper Search

Last updated: September 2026

Ripper Search is a browser extension that helps you search the Ripper.Store forum while browsing asset stores.

Summary

  • We do not operate our own servers or collect your personal data.
  • All data stays on your device unless you interact with third-party sites you already use.

Data stored locally

The extension uses chrome.storage.local for settings, search history, watched threads, and download metadata. This data never leaves your browser except when you export it manually.

Third-party services

forum.ripper.store — When logged in, the extension uses your browser session to search, post, and upvote via the forum API. We do not store your password.

Supported stores — The extension reads the current page URL and title to build search queries sent only to the forum API.

Permissions

PermissionPurpose
storageLocal settings and history
cookiesForum login session for API calls
notificationsAlerts for new downloads in watched threads
downloadsStart file downloads on user action
host permissionsPanel on store pages; forum API access

What we do not do

  • No analytics or tracking
  • No sale or sharing of user data
  • No account system operated by the extension author
